    Unseen tickets

    Sends 10 tickets worded in ways the model never trained on. Some will be unsure and go to human review.

    Malformed messages

    Puts bad JSON and an unknown schema version on the queue. They can never succeed, so they go straight to Failures without retrying.

    Model outage

    The classifier fails on every message. Tickets retry with growing delays, then land in Failures after the retry limit.
